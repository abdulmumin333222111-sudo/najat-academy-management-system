# Najat Academy Management System

Learn Quran, Build Character. A premium, secure, and full-stack management system built with Next.js, TypeScript, and MongoDB.

## 🚀 Features
- Role-Based Access Control (RBAC)
- Secure Student & Guardian Portals
- Exam & Result Management
- Payment System with Audit Logs
- Digital Library & Certificate Verification

## 🛠 Tech Stack
- Frontend: Next.js, Tailwind CSS
- Backend: Next.js Server Actions, API Routes
- Database: MongoDB (Mongoose)
- Security: JWT, RBAC, Data Isolation
